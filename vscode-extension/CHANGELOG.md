# Changelog

## 0.1.0

- First release.
- Live token count in the status bar for the active editor or selection.
- 50 popular open models bundled, so they work offline; any other Hugging Face model can be added by name.
- Warning threshold for prompt writing.
- Token breakdown view with colored tokens and optional token IDs.
- Hugging Face token stored in VS Code's secret storage for gated models.
